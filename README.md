## 🔎 Sobre o Projeto

O **Contador do YouTube** é uma ferramenta web simples, rápida e totalmente online feita para **monitorar estatísticas de canais do YouTube**. Com uma interface limpa em modo escuro (*Dark Mode*), a aplicação permite que qualquer criador de conteúdo ou entusiasta acompanhe o crescimento de um canal de forma visual e imediata.

---

## 🚀 Como Usar

A aplicação está hospedada na nuvem e pronta para uso. **Não é necessário instalar nada no seu computador**:

1. Acesse o link oficial do projeto: `https://github.io` *(substitua pelo seu link)*
2. Digite o nome do canal desejado no campo de busca.
3. Clique em **Buscar** para carregar os dados atualizados.

---

## 📋 Métricas Exibidas

Ao buscar por um canal, o painel exibe instantaneamente três informações essenciais:

*   **Inscritos:** Total de pessoas que seguem o canal.
*   **Visualizações:** A soma de visualizações acumuladas em todo o conteúdo.
*   **Total de Vídeos:** A quantidade de conteúdos já publicados na plataforma.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido focado na web moderna e na leveza do carregamento:

*   **HTML5** – Estruturação da página e campos de busca.
*   **CSS3** – Estilização visual com tema escuro e layout responsivo.
*   **JavaScript** – Integração com a API do YouTube e atualização dinâmica dos dados na tela sem recarregar a página.
